# Example country dataset

A tiny synthetic dataset included in `fscontextdemo` for demonstrating:

## Usage

``` r
fsdemo_country_data
```

## Format

A data frame with 5 rows and 3 variables:

- country:

  Country name or country code

- time:

  Observation year

- value:

  Synthetic numeric value
